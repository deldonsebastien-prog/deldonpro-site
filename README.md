# DeldonPro — site vitrine

Première version du site de **DeldonPro**, activité de Sébastien Deldon consacrée au développement commercial et aux solutions numériques pour les indépendants, TPE et PME.

## Contenu de la version 1

- page d’accueil responsive pour mobile, tablette et ordinateur ;
- présentation des services : prospection, relation client, CRM, automatisation et intelligence artificielle ;
- méthode d’accompagnement en quatre étapes ;
- présentation de l’expérience de Sébastien Deldon ;
- coordonnées cliquables et formulaire préparant un e-mail sans stocker de données ;
- mentions légales et politique de confidentialité intégrées ;
- référencement naturel de base.

## Prévisualisation locale

Ouvrir simplement le fichier `index.html` dans un navigateur.

## Avant la publication définitive

Les éléments suivants devront être complétés ou contrôlés :

- adresse professionnelle de l’entreprise individuelle ;
- numéro SIRET ;
- identité de l’hébergeur ;
- activation de GitHub Pages ;
- raccordement du domaine `deldonpro.fr` ;
- validation finale des textes, coordonnées et liens.

## Structure technique

Le site repose sur un unique fichier HTML autonome, sans base de données ni dépendance externe. Cette architecture facilite la maintenance, la rapidité d’affichage et l’hébergement statique.
